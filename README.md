## Descripción
Este proyecto contiene la implementación en lenguaje Java del algoritmo de **Ordenamiento por Burbuja**, aplicado sobre el arreglo `{6, 1, 5, 8, 3, 2, 7, 4}`. El programa muestra el estado del arreglo paso a paso en cada pasada hasta obtener la lista ordenada de forma ascendente.

## Requisitos previos
* Tener instalado el Kit de Desarrollo de Java (**JDK 8** o superior).
* Tener instalado **Git** para clonar el repositorio.

## Instrucciones para clonar, compilar y ejecutar

1. **Clonar el repositorio:**
   Abre una terminal o símbolo del sistema y ejecuta el siguiente comando:
   ```bash
   git clone https://github.com
   ```

2. **Ingresar a la carpeta del proyecto:**
   ```bash
   cd TU_REPOSITORIO
   ```

3. **Compilar el código fuente:**
   ```bash
   javac OrdenamientoBurbuja.java
   ```

4. **Ejecutar el programa:**
   ```bash
   java OrdenamientoBurbuja
   ```
